# Risk register

Likelihood and impact use Low / Medium / High. Owner roles refer to the delivery team, not product roles.

| ID   | Risk                                                                              | Likelihood | Impact | Mitigation                                                                                                                                                                                                                | Owner role        | Status                                          |
| ---- | --------------------------------------------------------------------------------- | ---------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ----------------------------------------------- |
| R-01 | Cross-tenant data leak through a query missing `organization_id`                  | Medium     | High   | Session-derived scope (`scopeOf`), repository functions take `organizationId` first, composite `(organization_id, id)` keys for future FKs, isolation integration tests per entity (facilities done; AO-056 for the rest) | Tech lead         | Open, partially mitigated                       |
| R-02 | Single `users.organization_id` blocks multi-organization users required by PRD §3 | High       | Medium | AO-007 introduces `memberships` and session-level active organization before more entities depend on the user table                                                                                                       | Tech lead         | Open                                            |
| R-03 | Concurrent stock issues drive balances negative (A-07)                            | Medium     | High   | Conditional `UPDATE ... WHERE on_hand_qty >= $qty` in the same transaction as the ledger insert; parallel-request test (ADR-0016, AO-042, AO-058)                                                                         | Backend engineer  | Open                                            |
| R-04 | Duplicate preventive work orders after restarts (A-09)                            | Medium     | Medium | Unique `(schedule_id, occurrence_date)` with `ON CONFLICT DO NOTHING`, advisory-lock leader (ADR-0015, AO-039)                                                                                                            | Backend engineer  | Open                                            |
| R-05 | Lost updates when two users transition the same work order                        | Medium     | Medium | `version` column with compare-and-set; 409 on mismatch (AO-024)                                                                                                                                                           | Backend engineer  | Open                                            |
| R-06 | SLA disputes because policy semantics are unclear                                 | Medium     | Medium | Semantics fixed in ADR-0014 and implemented in a pure, fully tested module (AO-022 done); UI explains elapsed-clock policy (AO-033)                                                                                       | Product owner     | Mitigated (domain), UI pending                  |
| R-07 | Malicious uploads (executables, path traversal, oversized files)                  | Medium     | High   | MIME allowlist by magic bytes, random stored names, size limit, tenant-checked download (ADR-0011, AO-020, A-14)                                                                                                          | Security champion | Open                                            |
| R-08 | Cost reports silently treat unknown rates as zero                                 | Medium     | Medium | Cost function returns explicit `incomplete` flags (AO-048); UI labels estimates (AO-051)                                                                                                                                  | Backend engineer  | Open                                            |
| R-09 | CSV export enables spreadsheet formula injection                                  | Low        | Medium | Prefix cells starting with `= + - @` and escape quotes (AO-049)                                                                                                                                                           | Security champion | Open                                            |
| R-10 | Restricted npm mirror lacks a dependency                                          | Medium     | Medium | Small dependency footprint; standard-library fallbacks (scrypt, crypto); lock file committed                                                                                                                              | Tech lead         | Mitigated                                       |
| R-11 | Estimate overrun on work-order screens and reporting                              | Medium     | Medium | Domain logic built first; CSV import and advanced charts are the agreed scope levers (PRD §10)                                                                                                                            | Product owner     | Open                                            |
| R-12 | Demo credentials reach a production database                                      | Low        | High   | Seed refuses `NODE_ENV=production`; credentials documented as development-only; production checklist in deployment plan                                                                                                   | DevOps engineer   | Mitigated                                       |
| R-13 | Audit rows diverge from business state                                            | Low        | High   | Audit written with the same transaction client (`recordAudit(tx, …)`), verified in facilities integration test                                                                                                            | Backend engineer  | Mitigated (pattern), applies to each new module |
| R-14 | Accessibility gaps on dense tables and the narrow technician queue                | Medium     | Medium | WCAG 2.1 AA target, axe checks in Playwright (AO-061)                                                                                                                                                                     | Frontend engineer | Open                                            |
